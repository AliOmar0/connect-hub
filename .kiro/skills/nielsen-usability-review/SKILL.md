# Nielsen Usability Review

Review the interface as a task flow, not only as a visual composition. Prioritize issues by user impact, frequency, and difficulty of recovery.

## Heuristic pass

1. **System status:** show what is loading, live, stale, saved, failed, or complete within a useful time.
2. **Real-world match:** use familiar domain language, units, ordering, and concepts instead of implementation terms.
3. **Control and freedom:** provide safe exits, undo/cancel where appropriate, and avoid trapping users in flows.
4. **Consistency:** reuse established components, labels, locations, and interaction patterns.
5. **Error prevention:** constrain invalid actions and clarify consequences before risky operations.
6. **Recognition:** keep choices, context, and next actions visible rather than relying on memory.
7. **Efficiency:** support both first-time and frequent users without cluttering the primary path.
8. **Minimal design:** remove decorative or duplicate information that competes with the task.
9. **Error recovery:** explain the problem in plain language, preserve user work, and offer a specific recovery action.
10. **Help in context:** add concise guidance only where the interface cannot be self-explanatory.

## Review output

- State the primary user and task.
- Record each issue with its violated heuristic and user consequence.
- Fix high-impact issues first; avoid cosmetic churn that weakens consistency.
- Check every control actually performs the action its label implies.
- Verify empty, loading, success, offline/stale, and error paths—not only the happy path.

Source: [Nielsen Norman Group's usability heuristics](https://www.nngroup.com/articles/ten-usability-heuristics/)
